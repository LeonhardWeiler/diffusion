Android note app with real files. Notes are plain files in a real Git repository, so you can use this app together with any desktop editor.

* open or clone repositories
* every file in the repository is listed, not only the notes
* notes search across the whole repository
* folder navigation
* rename and move, for notes and folders
* edit view with markdown rendering
* private repo, over SSH
* remote sync
* time based sort
* pure black theme for OLED screens
